## Personal projects

These are portfolio projects, separate from my professional work:

- [Digital Wallet API](https://github.com/Adri23Ausin/digital-wallet-api) - A multi-currency wallet API exploring idempotent transfers, concurrent updates and monetary correctness. Java 21, Spring Boot, PostgreSQL, Testcontainers and hexagonal architecture.
- [FX Rate Service](https://github.com/Adri23Ausin/fx-rate-service) - An exchange-rate API built around external data and provider failures: caching, retries, circuit breaking, stale-data fallback and monitoring with Prometheus and Grafana.
- [Bank Statement Batch](https://github.com/Adri23Ausin/bank-statement-batch) - A Spring Batch application for importing CSV statements, handling invalid and duplicate records, reconciling expected payments and generating monthly reports.

Each project includes setup instructions, tests and notes on design decisions and limitations.
